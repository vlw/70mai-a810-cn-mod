# 70mai A810 PRO (CN) — сборщик модифицированной прошивки

Собирает `FW98529A.bin` для китайского 70mai Dash Cam 4K A810 PRO (модель DR2830, прошивка **1.6.49**)
из стокового образа. Набор доработок выбирается в `config.env`. Сборка работает на macOS и Linux
(через Docker) или прямо на Linux.

Серийный номер, DID, ключи, регион (`CONFIG_DEV_CHN`), загрузчик и ядро не меняются.

Прошивок 70mai в репозитории нет и не будет: их нельзя распространять. Здесь только сборщик и описание,
а стоковые образы каждый берёт сам (см. «Что нужно»).

## Поддерживаемая версия

| | |
|---|---|
| Камера | 70mai Dash Cam 4K A810 PRO, китайская версия (модель DR2830) |
| Прошивка | **1.6.49** (2026-03-22), `FW98529A.bin` sha256 `abbfec494ad6e6dcfd2368cd8655f11902b658f1a243cea568e6e01fad2002c9` |
| main_app | md5 `0fa96a21bebfc9b7fcf8134d744c8dfd` |
| Донор (языки, голос) | A810S WW **1.5.40ww**, `FW98529A.bin` sha256 `d19499741d458d2043132d73e0b1b4a601c9ff1039b6ecc255cbb17f42577273` |

На другой версии сборка остановится на проверке хешей. Все адреса в патчах привязаны к этому main_app,
и для новой версии прошивки их придётся искать заново.

## Что умеет

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `LANGUAGE_MENU` | 1 | Пункт «Язык системы» в системных настройках вместо «Скачать приложение»: русский, английский и другие языки из WW. Нужен WW-образ |
| `TIMEZONE_MENU` | 1 | Выбор часового пояса на странице «Время системы» (пункт 0, когда включена синхронизация по GPS) |
| `DEFAULT_ENGLISH` | 1 | После сброса настроек язык английский, а не китайский (нужен `LANGUAGE_MENU`) |
| `DEFAULT_TZ` | `+3` | Часовой пояс после сброса: `+3`, `-5`, `+5:30`…; пусто = стоковый UTC+8 |
| `GPS_HOME` | 1 | Главный экран: значок GPS всегда виден (бледный, пока нет фикса), скорость под часами |
| `RU_LABELS` | 1 | Русское меню: «Формат видео» (длинная строка налезала), «Высокое сжатие (HEVC)», «Низкое сжатие (AVC)» |
| `HLG` | 1 | HDR-видео HLG в режимах 4K HDR и Full HD HDR передней камеры: кривая тона ISP и метка в потоке. Режимы без HDR и задняя камера как в стоке |
| `TELNET` | 1 | root-telnet без пароля на Wi-Fi камеры (`192.168.0.1:23`) |
| `GPS_WARM` | 1 | Тёплый старт GPS: после каждой загрузки прошивки модуля отдаёт ему время и последнюю позицию |
| `VOICE_RU_EN` | 1 | Русская и английская голосовые подсказки из WW-образа |
| `UPDATE_SCREEN_EN` | 1 | Английские экраны при прошивке с карты |

Как и почему работает каждый патч: [docs/PATCHES.md](docs/PATCHES.md).

## Что нужно

- **Docker** (Docker Desktop на Mac) или Linux с root, `mtd-utils`, `python3` и `pip install ubi_reader python-lzo`.
- **Стоковые образы** в папке `input/` (имена любые, распознаются по sha256):
  - **обязательно**: CN 1.6.49, либо файл для карты `FW98529A.bin`
    (sha256 `abbfec49…02c9`), либо OTA-пакет из кэша приложения 70迈 на телефоне
    `Android/data/com.banyac.midrive.app/files/ota/dashcam/OTA_2349_FULL_70mai_d2830_1.6.49_20260326_full.zip`;
  - **для `LANGUAGE_MENU` и `VOICE_RU_EN`**: WW 1.5.40ww для A810S, `FW_A810S_1.5.40ww_OTA.zip`
    или `FW98529A.bin` из него (sha256 `d1949974…7273`). Из него берутся голосовые подсказки и английская
    модель голосового управления: без неё камера с не-китайским интерфейсом падает.

Прошивки 70mai в репозиторий не кладутся (`input/` в `.gitignore`).

## Сборка

```sh
cp config.default.env config.env   # и поправить ключи под себя
./build.sh                         # Docker: macOS и Linux
./build.sh --native                # Linux без Docker, от root
```

Результат: `out/FW98529A.bin` и `out/build-info.txt` (какие фичи включены, md5 main_app, sha256 образа).
По пути сборщик проверяет:
- исходный main_app — именно CN 1.6.49;
- каждое заменяемое слово совпадает с ожидаемым;
- пересобранные UBI распаковываются в то же дерево файлов;
- контрольные суммы разделов и заголовка образа.

Также он печатает, чем rootfs и app отличаются от стока.

## Разборка

```sh
./unpack.sh input/FW98529A.bin              # -> unpacked/FW98529A.bin/
./unpack.sh out/FW98529A.bin unpacked/my    # любой образ или OTA-пакет внутри папки репозитория
```

В результате: `parts/` (сырые разделы), `fs09/*/rootfs`, `fs10/*/app`. Владельцы и
устройства при этом не сохраняются, это только для просмотра.

## Прошивка

1. Скопировать `out/FW98529A.bin` в корень карты (FAT32/exFAT).
2. Вставить карту и подать питание (от сети, не от компьютера). Не отключать до перезагрузки камеры.
3. Камера обновится и сотрёт файл.

Откат: так же прошить стоковый `FW98529A.bin` 1.6.49. Его делает U-Boot до запуска main_app,
поэтому откат работает, даже если камера с модом не загружается.

## Telnet и отладка

- `telnet 192.168.0.1`, пользователь `root`, без пароля. Доступен только из Wi-Fi камеры.
- Отключить: создать на карте пустой файл `telnet.off` и перезапустить камеру.
- Тёплый старт GPS: лог в `/var/run/70mai-gps-warm.log`; отключить: `touch /usr/bin/70mai-gps-warm.disabled`.

## Как устроено

```
build.sh, unpack.sh         обёртки: Docker или --native
config.default.env          ключи по умолчанию (config.env их переопределяет)
docs/PATCHES.md             как и почему работает каждый патч
docker/Dockerfile           debian + mtd-utils + ubi_reader
scripts/build-inner.sh      сборка: вход → распаковка → патчи → UBI → FW98529A.bin
scripts/unpack-inner.sh     разборка для просмотра
scripts/fw_input.py         поиск стоковых образов в input/ (bin, OTA, zip) по sha256
scripts/patch_main_app.py   правки main_app, таблица фич features()
scripts/hlg_cfg.py          HLG-кривая для imx678_hdr.cfg
scripts/ntk_*.py            разделы Novatek: split / repack / checksum
scripts/fdt_setprop.py      правка DTB на месте (язык экранов обновления)
files/telnet, files/gps-warm  файлы, добавляемые в rootfs
```

У каждой фичи main_app свой фиксированный адрес кода в пустотах бинарника. Поэтому любой набор
фич даёт для общих фич те же байты, а патчер проверяет совпадение каждого заменяемого слова со
стоком.
